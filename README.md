# Markdown 阅读器（Typora 风格）

一个面向 **Windows** 的双栏 Markdown 阅读器 / 编辑器，界面风格参考 Typora 与 PDF 阅读器：
左侧是大纲，右侧是正文，可一键在「编辑」（源码）与「预览」（渲染）之间切换。

> 技术栈：**Python 3 + PySide6（Qt6 原生控件）**，启动快、输入响应零延迟。

---

## ✨ 功能特性

| 功能 | 说明 |
| --- | --- |
| 🗂 **双栏布局** | 左栏大纲（按 `#` 层级缩进、可折叠），右栏正文 |
| 🔀 **编辑 / 预览** | 启动与打开文件时**默认展示预览（阅读）界面**；顶部按钮切换编辑模式（显示 `#`、`**` 等标记且可编辑） |
| 🔄 **大纲实时同步** | 编辑正文时左侧大纲自动刷新（220ms 防抖）；**预览区滚动时左栏自动高亮当前所在章节**（如滚到 1.1 Foo 内部，左栏显示选中 1.1 Foo，样式与点击一致） |
| 🎯 **点击跳转** | 点击左侧标题，右侧光标/视图自动定位并滚动到对应标题 |
| 🔍 **查找高亮** | 当前匹配 **橙色**（`#ff9800`）、其余全部匹配 **黄色**（`#fff59d`）；回车循环查找下一个；**大纲中命中标题同步标黄并加粗** |
| 🧭 **大纲收起/展开** | 大纲标题行末尾按钮，一键全部收起 / 全部展开目录层级 |
| 📂 **打开文件** | 支持「打开文件」按钮 **与拖拽** `.md` 文件；自动识别 UTF-8 / GBK / GB18030 / BOM 等编码 |
| 🖼 **图片渲染** | 正文中的本地图片（相对路径按 md 文件所在目录解析）直接在预览区渲染；超宽图片自动等比缩放到可视宽度、窗口缩放时自适应重适配；图片紧凑排版，图片下方无多余留白 |
| 🔍 **图片浮窗预览** | **单击预览区图片**弹出浮窗放大查看：滚轮以鼠标位置为中心放大 / 缩小（5% ~ 2000%），按住拖动平移；支持**一键全屏**；`Esc` 或右上角 ✕ 关闭 |
| 🕘 **历史记录** | 打开文件旁下拉列出最近打开的文件（去重、最近优先，最多 20 条），支持一键清空；`Ctrl+H` 快捷弹出 |
| 📄 **导出** | 一键导出 **PDF**（样式与预览一致）与 **DOCX**（正式文档排版：宋体正文、1.5 倍行距、页眉与页码、封面标题、真表格）；导出成功后可点「打开导出文件」直接用系统默认程序打开 |
| ⌨️ **F11 工具栏** | 一键隐藏 / 恢复顶部工具栏，获得沉浸式阅读窗口 |
| ℹ️ **关于** | 工具栏「关于」展示版本信息 |

## 🚀 快速开始

### 方式一：直接运行（开发/自用）

1. 安装 [Python 3.9+](https://www.python.org/downloads/)（安装时勾选 *Add Python to PATH*）。
2. 双击 **`运行.bat`**（会自动安装依赖并启动）。

   或手动执行：
   ```bat
   pip install -r requirements.txt
   python main.py
   ```

   也可以直接把 `.md` 文件拖到窗口里，或：
   ```bat
   python main.py 你的文件.md
   ```

### 方式二：打包成独立 EXE（推荐分发）

双击 **`打包成exe.bat`**，脚本会自动安装 PyInstaller 并打包。完成后产出两个版本：

```
dist\MarkdownReader\MarkdownReader.exe   文件夹版：启动最快（实测约 1.5 秒），自用推荐
dist\MarkdownReader.exe                  单文件版：启动稍慢（约 6 秒，需先解压），发人方便
```

- **文件夹版**：将整个 `dist\MarkdownReader` 文件夹一起复制使用，启动速度与源码运行持平。
- **单文件版**：仅一个 exe 文件，方便发给别人；启动时需解压到临时目录，故稍慢。

两个版本均免安装，可复制到任意 Windows 电脑双击运行（目标机器无需装 Python）。
打包会自动带上应用图标（`assets\icon.ico`），exe 文件与任务栏均显示自定义图标。

## 🖱 使用说明

> 面向最终用户的完整操作手册见 **[使用帮助.md](使用帮助.md)**（随打包产物一起分发）。

### 顶部工具栏（从左到右）

| 按钮 | 作用 | 快捷键 |
| --- | --- | --- |
| 📂 打开文件 | 打开 `.md` 文件 | `Ctrl+O` |
| 🕘 历史记录 | 下拉列出最近打开的文件，可清空 | `Ctrl+H` |
| ✏️ 编辑 / 👁 预览 | 编辑（源码） ↔ 预览（渲染）切换（默认展示预览界面） | `Ctrl+D` |
| 查找框 | 输入即实时高亮全部匹配；回车跳到下一个匹配（循环回绕）；框内 ✕ 清除高亮 | `Ctrl+F` / `Enter` |
| 📄 导出 PDF | 导出为 PDF | — |
| 📝 导出 DOCX | 导出为 Word 文档（A4 正式排版：宋体正文、1.5 倍行距、首行缩进、页眉与页码、封面大标题、真表格、图片自动缩放） | — |
| ℹ️ 关于 | 查看版本信息 | — |

> 提示：按 **F11** 可隐藏 / 恢复顶部工具栏（工具栏被隐藏时，状态栏会提示如何恢复）。

### 大纲
- 标题按 `#` 层级缩进，父子关系一目了然，可展开/折叠。
- **点击**任意标题 → 右侧跳转定位（编辑模式定位光标，预览模式滚动到标题）。
- **跟随高亮**：编辑模式下移动光标、预览模式下滚动正文，左侧大纲都会自动高亮当前所在章节（选中样式与点击一致）。例如右栏滚到 `1.1 Foo` 内部时，左栏会显示选中 `1.1 Foo`。
- 「大纲」标题行末尾的 **▲/▼ 按钮**：一键全部收起（▲）/ 全部展开（▼）目录层级。

### 历史记录
- 点击工具栏「🕘 历史记录」或按 `Ctrl+H`，下拉列出最近打开过的文件。
- 最近打开的在最前，同一文件不重复（最多保留 20 条）。
- 点击任一项即可打开该文件；文件已被移动/删除时会提示并自动移除失效记录。
- 菜单底部「🧹 清空历史记录」一键清空，无需确认。

### 查找
- 输入关键词即实时查找（按 `Ctrl+F` 快速聚焦查找框）。
- **当前匹配橙色高亮**，**其余匹配黄色高亮**，视图自动滚动到当前匹配处。
- **按回车**跳到下一个匹配，到末尾后循环回绕到第一个。
- 大纲中标题包含关键词的条目同步**标黄并加粗**（仅作位置提示，点击跳转行为不变）。
- 点击查找框内的 ✕ 清除全部查找高亮。

### 图片浮窗预览
- **单击**预览区中的任意图片 → 弹出深色浮窗放大查看（鼠标悬停图片时光标变为手型）。
- **鼠标滚轮**：以鼠标位置为中心放大 / 缩小（5% ~ 2000%）；按住左键可拖动平移图片。
- 标题条显示图片文件名，可按住拖动移动浮窗位置。
- 标题条右侧 **「全屏」按钮**：一键全屏查看（按钮变为「退出全屏」）；全屏时按 `Esc` 先退出全屏，再按 `Esc` 关闭浮窗。
- **`Esc` 键**或右上角 **✕** 按钮关闭浮窗。
- 浮窗首次打开时自动适配窗口（大图缩小显示、小图保持原始比例），切换全屏后自动重新适配。

### 关于
- 点击工具栏 **ℹ️ 关于** → 弹窗显示软件名称、版本号与技术栈。

## ❓ 常见问题

**Q：双击 `运行.bat` 闪退？**
A：多半是没装 Python 或未加入 PATH。请安装 Python 后重试；或手动在命令行运行 `python main.py` 查看报错。

**Q：打包很慢 / 体积大？**
A：打包会产出两个版本（文件夹版 + 单文件版），单文件版实测约 40 MB（仅内置 Qt 核心运行时 PySide6-Essentials）。首次打包较慢（约 2–4 分钟，需打包两次），后续会自动复用缓存。

**Q：软件启动有点慢？**
A：请使用**文件夹版**（`dist\MarkdownReader\MarkdownReader.exe`）——实测约 1.5 秒启动；单文件版每次启动需先解压，约 6 秒。日常自用推荐文件夹版，发给别人用单文件版。

**Q：打开文件中文乱码？**
A：程序已自动识别 UTF-8 / GBK / GB18030 / BOM 等常见编码；若仍异常，请确认文件不是 UTF-16 以外的罕见编码。

**Q：导出的 PDF 字体不对？**
A：PDF 使用系统字体渲染，请确保 Windows 已安装「微软雅黑」（默认自带）。

**Q：导出的 DOCX 是什么排版样式？**
A：采用正式文档规范：A4 纸张、正文宋体 + Times New Roman 10.5pt、1.5 倍行距、段首缩进 2 字符；页眉为文档标题、页脚为「第 X 页」；文档首个一级标题渲染为封面大标题；表格转为可编辑的 Word 真表格；代码块整体缩进且不显示 ``` 围栏；图片自动缩放（最大宽 14 cm）。

**Q：预览区里的图片什么时候能显示？**
A：图片按 md 文件所在目录解析相对路径（如 `![](plantuml/图.png)` 指向 md 同级的 `plantuml/` 目录），打开文件后即可看到；超宽图片会自动缩放到可视宽度、窗口变大变小时自动重适配，无需横向滚动。单击图片可弹浮窗放大查看（滚轮缩放、可全屏，`Esc` / ✕ 关闭）。导出的 PDF 同样会带上全部图片。
